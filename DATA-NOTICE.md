# Historical data attribution

Contains information from Cricsheet, https://cricsheet.org/, made available under the Open Data Commons Attribution License v1.0:

https://opendatacommons.org/licenses/by/1.0/

Original archive: https://cricsheet.org/downloads/wbb_json.zip

Cricsheet licensing notice: https://cricsheet.org/licensing/

The source archive was downloaded on 2 November 2026 and contained 519 Women's Big Bash League matches dated 18 December 2015–13 December 2025. This project transforms the source JSON into active legal-ball observations from eligible standard completed first innings. The observations omit player identities and match identifiers but retain the exact score, wickets, legal balls, eventual total and year needed to reproduce descriptive frequencies. This adaptation is not endorsed by Cricsheet, Cricket Australia or WBBL.

The original source data is not relicensed as application code. Retain this notice and source/license links when using or redistributing the data or derived results. No code license granting public reuse has been selected for this private learning project.
